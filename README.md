# 🍔 Food E-commerce Website

This project is a responsive **Food E-commerce Website** developed using **HTML, CSS, and JavaScript**. It is designed to provide a simple and interactive user experience with multiple pages and dynamic functionalities.

## 📌 Project Overview

The website consists of three main pages:

* **Home Page** – Displays branding, navigation, and featured content.
* **Order Page** – Allows users to browse food items and filter them using a dynamic search feature.
* **Contact Page** – Includes a fully functional form with real-time validation and a character counter.

The project focuses on building strong front-end development skills, including **responsive design, DOM manipulation, and event handling**.

## 📋 Contact Form Functionalities

### ✅ Real-Time Form Validation

The contact form includes the following fields:

* **Name**
* **Email**
* **Password**

Validation features:

* Ensures the **Name field is not empty**.
* Validates **Email format** using JavaScript.
* Checks that **Password has a minimum of 6 characters**.
* Displays **error messages dynamically**.
* **Submit button is disabled** until all inputs are valid.
* Prevents form submission if validation fails.

---

### ✉️ Textarea with Character Counter

* Users can type a message in a textarea.
* Displays a live counter (e.g., **"150/200 characters"**).
* Updates in real-time using the `input` event.
* Prevents typing beyond **200 characters**.
* Shows a warning message when the limit is reached.
